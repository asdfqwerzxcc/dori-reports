1. Method and evidence

  • Versions and licences: https://registry.npmjs.org/<package>/latest, read 2026-10-22 (§2 table).
  • Glyph counts and icon-name lists: the Iconify datasets served per set as https://cdn.jsdelivr.net/npm/@iconify-json/<prefix>@latest/icons.json (the api.iconify.design endpoint returned HTTP 429 during this pass; the npm data is the same dataset).
  • Repo audit: pascalorg/editor tarball at commit b1a29ed676b34a5df6db3f94f9036b2c62c51406, unpacked read-only into a temp directory and scanned locally (§5).
  • Coverage: exact icon names were probed against each set's name array, then hand-audited to remove keyword false positives (e.g. Lucide face-grinning, Tabler uv-index, Phosphor's *-light weight suffixes). Probe keywords are in the appendix so the matrix can be re-run.
  • Standards: W3C, Apple, Material, Carbon, Lucide, Tabler and Radix pages, quoted in §8.

Set notes:

  • Lucide — the geometry the fork already ships: viewBox="0 0 24 24" stroke-width="2" stroke-linecap="round", verified in lucide-static 1.61.0 icons/move-3d.svg. ISC means no attribution obligation in the product.
  • Tabler — verified stroke-width="2" on a 24 canvas (@tabler/icons icons/outline/gizmo.svg). Ships -filled variants, which is how an active state can be expressed without a second family.
  • Phosphor — 6 weights on one 256-unit grid; its README states "1,248 icons and counting", "6 weights", "Designed at 16 x 16px" (https://github.com/phosphor-icons/homepage). The 9,161 count is the weight-expanded dataset.
  • Material Symbols — the only free family with equipment glyphs (valve, water-pump, heat-pump, oil-barrel, sensors, gas-meter, electric-meter) but it is a filled-path set whose per-icon SVGs use viewBox="0 -960 960 960" at 48 px, and the full variable font is 7.9 MB; per-icon SVG (@material-symbols/svg-400, 13.1 MB unpacked) is the only tree-shakeable route.
  • Iconoir — unique 3D vocabulary (extrude, select-edge-3d, box-3d-point) but its SVGs are stroke-width="1.5" on a 24 canvas (https://cdn.jsdelivr.net/npm/iconoir@latest/icons/regular/extrude.svg), so mixing it with a 2 px set produces a visibly lighter glyph. That one fact is why it is not the secondary.
  • Radix Icons — 15 px grid, 342 glyphs: a UI-decor set, not a product icon system.
  • Font Awesome / Solar / Boxicons — attribution (CC-BY-4.0) is a product-visible obligation; keep them out of a shipped SCADA UI.

Implications for the fork: the existing language is outline monochrome at 14–16 px, in 32 px toolbar buttons and 36 px rail buttons, on a 44 px rail — i.e. Lucide is already being rendered well below its 24 px design size (effective stroke ≈ 1.33 px at 16 px). Two inconsistencies to fix rather than copy: (a) glyph sizes drift across 10/12/14/16/20/24 px with no rule, (b) node identity is carried by 101 raster .webp images that cannot inherit currentColor, while actions are vector — a SCADA fork needs monochrome, themeable equipment symbols instead.

7. Recommendation

7.1 Primary — Lucide, with import strategy

  • One named import per icon, never a barrel import; sideEffects: false keeps the bundle at the glyphs actually referenced: import { Bell, History, Gauge } from "lucide-react".
  • Default size comes from one wrapper, not from per-call classes — the fork currently has 10 different sizes (§5). Create components/icon.tsx that renders from a 4-value scale (12 / 14 / 16 / 20) and sets aria-hidden unless a label is given.
  • Stroke: leave strokeWidth at the library default of 2 on the 24 px grid; at 16 px that renders 1.33 px. Do not set strokeWidth={2} on a 16 px-scaled icon expecting 2 px, and do not mix in 1.5 px sets (Iconoir) or 512-unit filled sets (Font Awesome).
  • Icon-only buttons get aria-label + tooltip; the fork already has Toolbar.Tooltip (apps/editor/components/toolbar-tooltip.tsx, Radix).

7.2 Secondary — Tabler, allowed only for these glyphs

Permitted list (each verified present in @tabler/icons-react 3.49.0): gizmo, layers-union, layers-subtract, layers-intersect, layers-difference, 3d-cube-sphere, rotate-3d, perspective, polygon, vector-triangle, arrows-move, arrows-maximize, magnet. Anything outside that list means "draw it" or "Lucide already has it".

Rule: the secondary is allowed only inside the 3D viewport toolbar and the mesh-edit mode switcher. It is not allowed in the SCADA chrome (alarms, trends, asset tree, tables) — mixing families there is what makes an app look assembled instead of designed.

7.3 Must-be-custom SVG (20 glyphs)

Drawn on the same 24 px box: fill="none", stroke="currentColor", stroke-width="2", stroke-linecap="round", 1 px padding — Lucide's own rules (https://lucide.dev/contribute/icons/design-principles).

7.4 Rejected, and why

  • Material Symbols as primary — the best industrial vocabulary (14/15 in §3, against Lucide's 12/15) but the wrong tool: 16,442 glyphs behind a 7.9 MB variable font, no sideEffects: false, and filled-path geometry on a 48 px viewBox that fights a 2 px stroke set. Its equipment glyphs are also generic Google symbols, not P&ID symbols, so they do not remove the custom sheet — they add a second visual language instead.
  • Iconoir as secondary — has extrude, select-edge-3d, box-3d-point, but stroke-width="1.5" (https://cdn.jsdelivr.net/npm/iconoir@latest/icons/regular/extrude.svg) against the fork's 2 px.
  • Font Awesome / Solar / Boxicons — CC-BY-4.0 attribution obligations in a shipped product.
  • Icon fonts of any kind — no per-glyph tree-shaking, no currentColor control at the component level, poor rendering at 14 px, and screen-reader noise.
  • @iconify/react for the app's own chrome — fine as the fork's plugin escape hatch (icon-ref.tsx), not as the app's icon source: it resolves icons at runtime and defeats static analysis.

  • Iconify HTTP API returned 429 during this pass; all counts therefore come from the same dataset served as npm packages at cdn.jsdelivr.net/npm/@iconify-json/*, which is a citable, reproducible source.
  • Glyph counts are dataset entries, not "distinct concepts": Phosphor's 9,161 = 1,248 icons × 6 weights; Material Symbols' 16,442 includes outline/rounded/sharp variants.
  • Spline glyph pixel size is a visual reading of an official screenshot, not a measurement of Spline's CSS.
